### 🧩 My Journey

####  TinyLM
My first step into building small language models — experimenting with **character-level RNNs** and simple **Transformers** in NumPy and JavaScript.  
It taught me how embeddings, attention, and backpropagation truly work under the hood.

#### ⚙️ RegEx — Regular Expression Engine
A fully custom **Regular Expression matcher** built from scratch.  
It explores the core principles of tokenization, parsing, and execution of pattern logic — building the foundation for how languages and interpreters work.

#### 📄 Proprietary PDF SDK
An in-house **PDF processing SDK** designed with a **recursive descent parser** and **custom tokenizer**.  
It powers advanced document tools like summarizers and Q&A systems — extracting structure and context from complex PDFs.

#### 🚀 Upcoming: Vriti (M4 → Vriti 1.0)
The next stage in my journey — **Vriti**, a small and efficient **language model** inspired by TinyLM.  
Vriti represents the fusion of all my past experiments — combining interpretability, efficiency, and creativity.
